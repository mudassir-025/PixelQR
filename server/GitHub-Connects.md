# GitHub Connects

### GitHub Connects Routine

```
git status
git diff
git add index.html
git diff --staged
git commit -m "Updated the Client Server"
git push
```

| Terminal            | VS Code              |
| :------------------ | :------------------- |
| `git status`        | Source Control panel |
| `git add .`         | Stage Changes +      |
| `git diff`          | Click changed file   |
| `git diff --staged` | Click staged file    |
| `git commit`        | Commit button        |
| `git push`          | Sync/Push            |
| `git pull`          |                      |
